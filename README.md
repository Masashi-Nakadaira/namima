# 波間 — NAMIMA

波の干渉模様を見て、位相・波長・振幅・波源の位置を復元する、5問1セットのパズルです。

- イージー：2つのつまみ
- ノーマル：3〜4つのつまみ
- ハード：5〜7つのつまみ
- 各問で波色が変わります。お題と操作側は同じ色・同じ縮尺で、色は採点に影響しません
- 調整中の一致率は非表示。「判定する」で一致率と正解設定の一例を表示します
- セット得点は各問の**最初の判定**を合計した500点満点。判定後の再調整は練習で、記録を上書きしません
- 結果は端末の共有機能、クリップボード、手動コピーで共有できます。ヒント利用数を含め、自動投稿はしません

## 表示言語

ブラウザの優先言語に合わせて、日本語・英語・韓国語・簡体字中国語・繁体字中国語・フランス語・ドイツ語・インドネシア語・タイ語・ベトナム語を自動選択します。対応しない言語しかない場合は英語になります。

- 右上の地球アイコンで手動変更できます。「自動」に戻すとブラウザ設定に従います
- 手動設定は端末内の `namima-language-v1` に保存します。保存できない環境でも、そのページ内の切り替えは動作します
- 中国語は明示された `Hans` / `Hant` を優先し、TW・HK・MOは繁体字、その他の地域と地域未指定は簡体字にします
- 言語を変えても現在の問題・操作履歴・点数・ヒント利用・URLは変わりません
- 説明、操作名、読み上げ用ラベル、ヒント、結果、共有文を翻訳します。位置情報・IP判定・外部翻訳サービスは使いません
- 翻訳は `docs/i18n.js` にまとめています。波のモデルと問題生成・採点ロジックは変更していません

## ローカルで遊ぶ

ビルドやサーバー処理は不要です。リポジトリのルートで以下を実行します。

```sh
python3 -m http.server 4173 --directory docs
```

ブラウザで `http://localhost:4173` を開きます。`docs/` の全ファイルは相対パスで動作し、GitHub Pagesのプロジェクトパスにも対応します。共有URLは表示中のページからクエリとフラグメントを除いて生成します。

## テスト

Node.js 22.12以上と開発用のjsdomを使用します。ゲーム本体に外部依存はありません。

```sh
npm install
npm test
```

既存のjsdomを使う場合は、`QA_JSDOM_PATH` にそのモジュールへの絶対パスを指定できます。

## モデルと点数

同じ周波数の円形波を複素振幅として加算します。強度は波源数の二乗で割る共通のスケールです。416サンプルの強度の二乗平均平方根誤差から一致率を計算し、小数1桁まで表示します。パラメーターが違っていても、等価な模様なら同じ点数です。これは教育・表現用の簡略モデルであり、流体の厳密なシミュレーションではありません。

目標は操作できる刻みに合わせて生成され、初期状態がすでに正解に近い問題は避けます。生成・採点は端末内だけで行い、分析ツール・広告・API・自動データ送信は使っていません。
